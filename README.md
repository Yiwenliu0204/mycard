# mycard

## 把你的想法告訴 AI

呆一布 AI 節日卡片工作坊簡報，共 58 頁。此公開版不含講者筆記；講師原始檔保留於本機。

- 首頁：`index.html`
- 操作：方向鍵換頁，O 總覽；可切換全螢幕。
- 圖片：點擊放大，左右鍵切圖，Esc 關閉。
- 最後一頁為 YouTube 影片，從 1:56 開始，播放需要網路。
- 字型授權：`assets/fonts/gensen/SIL_Open_Font_License_1.1.txt`。
